# Compiler directives

Edit [MicroArch.toml](https://github.com/rsd-devel/rsd/blob/develop/Processor/Config/MicroArch.toml): `parameters` holds common values, while `overrides.simulation` and `overrides.synthesis` replace selected values for each mode.

Normal make invocations regenerate `Config/MicroArchConf.sv`, `Config/MicroArchMacros.svh` and `Makefiles/MicroArch.inc.mk`. These generated files are tracked in Git; edit the TOML or `Config/MicroArchConf.template.sv`, not the outputs. Tool/board settings remain in [Config/SynthesisMacros.sv](https://github.com/rsd-devel/rsd/blob/develop/Processor/Src/Config/SynthesisMacros.sv).

`RSD_SRC_CFG` applies to simulation and software builds. Synthesis defaults are emitted as `RSD_SYNTHESIS_SRC_CFG` and the generated header; netlist testbenches also use synthesis settings. A command-line `RSD_SRC_CFG` override does not change synthesis. Disable a Boolean macro by omitting it; defining it as `0` still enables it.

## Microarchitecture and instruction configuration

| Name | Meaning and default |
| --- | --- |
| `RSD_MARCH_INT_ISSUE_WIDTH` (`int_issue_width`) | Integer issue width: 1 or 2; default 2 |
| `RSD_MARCH_FP_PIPE` (`enable_fp_pipe`) | Enable the FP pipeline; enabled by default |
| `RSD_MARCH_UNIFIED_LDST_MEM_PIPE` (`enable_unified_ldst_mem_pipe`) | Unify load/store pipelines; undefined by default |
| `RSD_MARCH_UNIFIED_MULDIV_MEM_PIPE` (`enable_unified_muldiv_mem_pipe`) | Integrate multiply/divide into the memory pipeline; undefined by default |
| `RSD_ENABLE_ZBA` (`enable_zba`) | Enable Zba instruction decoding; enabled by default |
| `RSD_ENABLE_ZICOND` (`enable_zicond`) | Enable Zicond instruction decoding; enabled by default |
| `RSD_ENABLE_ZICFILP` (`enable_zicfilp`) | Enable Zicfilp landing-pad protection; enabled by default |
| `RSD_NARROW_PC` | Compress the PC representation; generated from `memory_map.pc` in `Processor/Config/MemoryMap.toml`, disabled by default |

`RSD_HAS_FP` is a make variable derived from `RSD_SRC_CFG`, not an RTL directive. It keeps FP test selection and compiler ISA flags consistent. After changing FP configuration, clean and rebuild both the simulator and programs, using the same configuration for execution.

## Build mode

| Name | Purpose |
| --- | --- |
| `RSD_FUNCTIONAL_SIMULATION` | Enable simulation code |
| `RSD_SYNTHESIS` | Enable synthesis code |
| `RSD_POST_SYNTHESIS` | Configure synthesis of the netlist used in post-synthesis tests |
| `RSD_POST_SYNTHESIS_SIMULATION` | Configure simulation of that netlist with the testbench |
| `RSD_SYNTHESIS_VIVADO` / `RSD_SYNTHESIS_SYNPLIFY` | Select the synthesis tool |
| `RSD_SYNTHESIS_ZEDBOARD` / `RSD_SYNTHESIS_ZYNQ` | Zedboard configuration / Zynq implementation paths |
| `RSD_SYNTHESIS_DESIGN_COMPILER` | Experimental Design Compiler synthesis |
| `RSD_USE_EXTERNAL_MEMORY` | Select the external-memory implementation path |

The Makefiles and synthesis scripts supply these directives. `RSD_POST_SYNTHESIS` and `RSD_POST_SYNTHESIS_SIMULATION` apply at different stages. Use the corresponding build target for normal operation.

## Debugging and internal controls

| Name | Purpose |
| --- | --- |
| `RSD_DISABLE_DEBUG_REGISTER` | Omit debug registers, affecting pipeline tracing and related output |
| `RSD_DISABLE_PERFORMANCE_COUNTER` | Generated by `enable_performance_counter = false`; disabled only for synthesis by default.  Omit microarchitecture counters in `Debug/PerformanceCounter.sv`; separate from the `mcycle` CSR |
| `RSD_STOP_FETCH_ON_PRED_MISS` | Control waiting after a prediction miss in `NextPCStage.sv`; its local definition is commented out by default |
| `RSD_ENABLE_REISSUE_ON_CACHE_MISS` | Select memory replay paths; currently defined inside `MemoryTagAccessStage.sv` |

The last two entries are source-level controls; arbitrary combinations are not established as tested `RSD_SRC_CFG` configurations.
